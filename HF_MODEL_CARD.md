# tsjit — Time-Series JIT Compiler & Sub-Microsecond Streaming Runtime

**`tsjit`** is an open-source (Apache-2.0) clean-room compiler and streaming runtime targeting the latency, precision, and multi-agent bottlenecks of time-series foundation models (`Datadog/Toto-2.0-4m`, `Datadog/Toto-2.0-22m`, `autogluon/chronos-bolt-small`, `amazon/chronos-2`) and real-time online statistical inference.

## Quickstart

```bash
pip install tsjit
tsjit info
tsjit verify
tsjit bench
```

```python
import tsjit

compiled = tsjit.compile(pipeline, horizon=16, context_length=512, precision="a10-auto", verify=True)
q = compiled.predict_quantiles(x)
```

## Limitations & Failure Boundaries

- `Toto-2.0` `fast-tf32` fails `10/512` (`4m`) and `3/512` (`22m`) under `25%-NaN` stress inputs; `a10-auto` (`mode="exact"`) automatically escalates `Toto-2.0` trunk linears to `fp16x3` (`0/1,536` failures).
- `Chronos-2` `O(B)` attention collapse applies to independent singleton streams; multi-series groups automatically fall back to exact grouped attention.
- Standalone `Scaled-FP16` / `FP16x3` wins at `M >= 2048` and is launch-overhead-bound at `M <= 1024` unless captured inside a CUDA Graph.
- Persistent SMEM IPCG should refresh preconditioner `M0` every `<= 8` steps (FP64) or `<= 16` steps (FP32); non-converged rows automatically fall back to GPU Cholesky.
- 1-tick asynchronous streaming (`gap_async` / `event_gated`) trades `+1.9%` to `+20.7%` CRPS on volatile GIFT-Eval datasets in exchange for non-blocking sub-microsecond arrival and calibrated intervals.
